# 当前位置与交易决策框架

## 目录

1. 定位与默认参数
2. 数据与四道决策门
3. 动作与仓位矩阵
4. 止损与退出规则
5. 输出约束

## 1. 定位与默认参数

- 输出条件化研究动作，不承诺收益，不把单一信号当作个人化指令。
- 优先使用用户明确给出的总资金、已有仓位、成本价、单股仓位上限和止损比例。
- 用户未指定时，读取仓位上限、仓位档位和止损比例自仓库根目录 `AGENTS.md` 的 `项目级个股交易决策默认值`；不在本 Skill 复制这些数值。
- 已有仓位高于项目级上限时，先提示超限，不建议继续加仓。
- 组合计划风险按 `目标仓位 × 止损比例` 计算。同时提示跳空、跌停、停牌或流动性不足可使实际损失超过计划值。

## 2. 数据与四道决策门

在输出买入动作前，同时通过以下四道门：

1. **基本面门**：基本面不得为 `偏弱 / 高风险`，财务质量不得为 `存疑`，财务造假风险初筛不得为 `高`。
2. **估值门**：用同行、自身历史区间、盈利质量和周期位置验证估值。低 PE/PB 不得单独通过此门。
3. **位置门**：使用足够新的日线/周线 OHLCV，按 `$trend-health-check` 得到价量标签，并识别支撑、结构失效位和是否过度乖离。数据不足时只能等待。
4. **风险收益门**：用估值、盈利情景或可验证的关键价位给出上行依据。原则上要求可验证上行空间不低于当次止损比例的两倍，即预期盈亏比不低于约2:1。

任一门缺少关键证据时，不得输出 `可以分步买入`。

## 3. 动作与仓位矩阵

| 基本面/估值 | 价量位置 | 主要动作 | 目标仓位 |
|---|---|---|---:|
| 强或证据充分的中性，估值有安全边际 | 走势健康，入场位与止损兼容 | 可以分步买入 | 项目级上限档 |
| 逻辑可跟踪，估值有吸引力 | 技术信号混合但未转弱 | 小仓试错 | 项目级试错档 |
| 基本面尚可 | 远离支撑、短期过度上涨或数据不足 | 等待 | 0% |
| 中性且财务质量一般 | 走势转弱 | 等待；已持仓者评估降仓 | 空仓档/试错档 |
| 逻辑未破坏 | 已持仓且属正常波动 | 持有观察 | 不高于项目级上限 |
| 基本面偏弱、高风险或核心假设失效 | 任意 | 降仓或退出 | 0% |

- `可以分步买入` 必须给出分步触发条件，不得等同于一次性到达项目级上限档。
- `小仓试错` 使用项目级试错档；未确认走势或基本面改善前不得加至上限档。
- 不明确用户持仓状态时，分别写 `未持仓：……` 和 `已持仓：……`，不自行假定。

## 4. 止损与退出规则

- 价格止损价按 `实际买入均价 × (1 - 止损比例)` 计算，同时列出关键结构失效位。
- 若有效结构止损需要超过用户当次参数或项目级默认止损上限，判定当前入场与风控不兼容，输出 `等待`，不放宽止损。
- 同时设定基本面提前退出条件，例如核心盈利大幅低于预期、经营现金流持续恶化、订单假设被证伪、重大治理/审计风险或估值前提消失。
- 基本面假设已失效时，不必等待价格跌满10%。
- 止损触发后不得自动补仓；重新建仓前必须重做基本面、估值与价量检查。

## 5. 输出约束

- 指明参考收盘价和行情日期；动作有效期原则上不超过下一个重大公告、下一份定期报告或明显价量结构变化的较早者。
- 买入区间、不宜追高位置、止损和目标价必须有可追溯的估值或价量依据，不使用任意整数。
- 将事实与判断分开。将目标价或上行空间标记为情景估算，不得表述为必然达到。
- 买入动作至少列出一条重要反证；降仓或退出至少列出一条可以避免过早看空的反向验证点。
- 结尾自然提醒：这是基于当前证据和既定风控参数的研究建议，不是确定性收益承诺。
