# 当前投资价值与介入条件

## 默认研究范围

观察未来 12—24 个月；用户另有期限时从其要求。结合业务质量、正常化盈利、现金流、估值和治理风险，判断当前价格是否值得承担风险。明确行情日期、估值期间及关键假设，完整计算放报告第 8 节。

不默认进行技术择时，不要求 OHLCV、支撑压力、突破确认或固定 2:1 盈亏比。技术走势检查由用户按需单独调用，不作为基本面评级的必要条件。

## 判断标准

| 当前判断 | 所需依据 |
|---|---|
| 有吸引力 | 公司质量与财务证据支持投资逻辑；可追溯的基准估值情景支持安全边际，主要风险可以接受；不能仅靠乐观情景或低 PE/PB |
| 合理但优势有限 | 经营逻辑成立，但当前价格已反映大部分可支持的预期，安全边际有限 |
| 已透支 | 当前价格需要偏乐观的盈利、增长或估值假设才能解释，应说明这些假设为何苛刻 |
| 暂无法判断 | 关键财务、价格或估值证据缺失或相互冲突，无法可靠归类；明确缺口及验证方式 |

不要为了增加正面结论而降低证据标准，也不要把证据不足统一写成“等待”。重大治理、审计或经营风险不可被便宜估值抵消，须在判断依据与推翻条件中明确揭示；无法建立可靠估值时使用“暂无法判断”，并说明是否应回避该风险。

## 估值与条件

- 根据行业选择可解释的估值方法，周期公司使用正常化盈利，不机械外推高景气利润。
- 区分保守、基准与乐观假设，说明依据和主要反证。缺乏量化基础时保留定性判断与证据缺口，不硬造目标价。
- 若计算回报，注明期间、是否含分红及资本开支等假设，区分累计回报与年化回报，不将估值上行当作必然收益。
- 介入条件可以是有依据的价格区间，也可以是盈利兑现、现金流改善等经营证据；不能用任意折扣或整数制造安全边际。
- 推翻条件写使判断失效的经营、财务与治理事件。价格显著变化或重大披露后重估，不因日常短线波动自动推翻经营逻辑。
- 按 SKILL.md 第 3.3 节输出标准表格字段，引用第 8 节，不重复铺开计算。

## 用户明确要求交易计划时

- 先运行仓库 `python scripts/portfolio_cli.py snapshot`，核验 `dataStatus` 与 `asOf`；失败或过期时明确无法核验，不用历史报告或公开 HTML 代替。用户提供更新的券商信息时以其为准。
- 风控参数取用户当次要求，否则引用根目录 AGENTS.md 的项目级默认值。不得在本文件复制默认数值。
- 区分投资吸引力和账户执行条件。结合实际仓位、资金与风险给出条件化动作，不将“有吸引力”直接映射为满额目标仓位；未知持仓不自动视为未持仓。
- 提供参考价格及日期、动作、目标仓位、执行条件、成本止损、基本面提前退出条件和重审触发事件。计划入场的止损只能标为假设，不能冒充实际成本止损。
- 价格止损按实际买入均价乘以一减止损比例计算；组合计划风险按目标仓位乘止损比例计算，并说明跳空、跌停、停牌和流动性可能扩大损失。
- 基本面逻辑失效时无需等待价格止损；止损后不自动补仓。任何价位必须有可追溯依据。
- 不强制技术走势、结构止损或固定盈亏比；用户另外要求技术执行分析时单独提供，不反向覆盖基本面判断。
