### 1.2 一句话核心判断

> **当前（2026 年 7 月）医药板块的核心主线 = 创新药景气复苏（政策+出海）→ CXO"卖水人"订单回暖 → 减肥药 GLP-1 是最强产业 β。** 三个主题是同一条产业链的不同环节，建议沿着"产业景气 → 订单兑现 → 利润兑现"的链条择股，而非孤立看待。

### 1.3 三个主题的逻辑串联

```
[Biotech / 创新药] ──融资回暖、政策扶持──→ 研发投入↑
        │
        ├──→ [CXO 卖水人] 订单↑、收入↑（当前兑现处）
        │           │
        │           └──→ [GLP-1 减肥药] 最强子赛道
        │                  ├── 礼来/诺和诺德（品牌方）
        │                  └── 凯莱英/药明康德/康龙（CDMO 卖水人）
        │
        └──→ [License-out 出海] BD 交易活跃 → 首付款回流 → 继续研发
```

### 2.3 主题三：减肥药 500 亿美元销售故事

#### 2.3.1 核心叙事

**"500 亿美元单品"** 指礼来（LLY）的**替尔泊肽（Tirzepatide）**单一分子——Mounjaro（降糖）+ Zepbound（减重）两品牌合计——有望在 2026 年冲击约 **500 亿美元**年销售额。
- 2025 年实际合计 ~$365 亿，已登顶"药王"
- 2026 Q1 单季 ~$128 亿，年化节奏已达 $500 亿级

#### 2.3.2 两强对比

| 指标 | 替尔泊肽（礼来 LLY） | 司美格鲁肽（诺和诺德 NVO） |
|------|------|------|
| 2025 全年 | ~$365 亿 | 增速放缓，持续下修 |
| 减重效果 | ~20% | ~14% |
| 2026 指引 | 公司总营收 $800–830 亿 | 7 月下调，市值蒸发 ~$900 亿 |
| 靶点 | 双靶点 GLP-1+GIP | 单靶点 GLP-1 |

**判读**：礼来双靶点优势明显，注射剂之争基本已分胜负；诺和诺德先发优势被稀释。

#### 2.3.3 核心标的与梯队

| 梯队 | 标的 | 逻辑 |
|------|------|------|
| **第一（确定性最高）** | 礼来（LLY） | 替尔泊肽主导者，2026 指引 $800–830 亿 |
| **第二（先发但承压）** | 诺和诺德（NVO） | 司美格鲁肽增速骤降，押注口服剂型 |
| **第三（2027 后）** | 罗氏、辉瑞、安进、信达、恒瑞 | 第三名抢位战 |
| **卖水人（CDMO）** | 凯莱英、药明康德、康龙化成 | 多肽 CDMO 受益（康龙手握礼来 Orforglipron 订单） |

#### 2.3.4 风险点（6 项）

1. 定价压力（医保/IRA 谈判）
2. 口服剂型竞赛（orforglipron vs 口服 Wegovy 25mg）
3. 第三名抢位（2027 后格局重塑）
4. 产能/依从性瓶颈
5. 安全黑天鹅
6. 估值过高（尤其礼来市值已透支较多预期）

### 2.4 主题四：Biotech 概念与投资框架

#### 2.4.1 定义

**Biotech（生物科技）** = 利用生物体/生物系统开发产品的产业。投资语境下特指**生物医药行业**，涵盖大分子生物药、基因/细胞治疗（CGT）、mRNA、ADC 等新技术路径。

#### 2.4.2 Biotech vs Pharma 对比

| 维度 | Biotech | Pharma（传统药企） |
|------|---------|------|
| 技术路径 | 生物大分子、新技术平台 | 化学小分子、成熟工艺 |
| 研发模式 | 平台技术 + 管线推进 | 收购 + 自研 + 进口替代 |
| 现金流 | 长期亏损，靠融资输血 | 稳定正现金流 |
| 估值方法 | **rNPV（风险调整净现值）** | PE / EV/EBITDA |
| 催化剂 | 临床数据读出 / FDA 审批 / BD 交易 | 财报、分红、并购 |

#### 2.4.3 四大投资特征

1. **高风险高回报**：单一管线临床成功率 <10%
2. **催化剂数据驱动**：临床 readout、FDA 审批、BD 交易是股价主驱动力
3. **利率敏感**：长久期资产，对美债利率高度敏感
4. **融资环境是生命线**：投融资回暖直接转化为 CXO 订单

#### 2.4.4 Biotech 在产业链中的位置

```
Biotech（创新来源）──→ 创新药研发 ──→ CXO（卖水人）服务
     │                                    │
     └── BD/License-out 出海 ──→ 首付款回流 ──→ 继续研发 ──→ CXO 订单↑
```

**判读**：Biotech 融资景气度是 CXO 订单的**领先指标**。2026 年创新药大涨的四重共振（政策+估值+业绩+出海），最终都汇入 CXO 的订单回暖。

#### 2.4.5 相关指数

- 美股：**XBI**（SPDR S&P Biotech）、**NBI**（Nasdaq Biotech）
- A 股：科创生物
- 港股：恒生医疗保健

## 第三部分：投资策略与风险提示

### 3.1 优选逻辑（三因子）

**赛道增速 × 利润率水平 × 订单可见度**

| 优选顺序 | 标的 | 逻辑 |
|----------|------|------|
| **首选** | 药明生物 | 大分子 + ADC，利润率提升中，backlog 237 亿美元 |
| **次选** | 凯莱英 | 小分子 + 多肽（GLP-1），毛利率最高 |
| **稳健** | 药明康德 | 综合龙头，规模最大，需折扣计入政策风险 |
| **弹性/跟踪** | 康龙化成 | 订单加速但利润率最低，跟踪拐点 |
| **海外确定性** | 礼来（LLY） | GLP-1 双靶点赢家 |

### 3.2 风险提示（判断可能失效的因素）

1. **地缘政治**：药明康德、药明生物北美收入占比高，美国《生物安全法案》仍是最大不确定因素
2. **产能过剩**：国内 CDMO 集体扩产（康龙 50 亿、凯莱英 ADC 平台），若需求放缓将引发价格战
3. **周期属性**：CXO 是强周期行业，2022–2023 年加息期订单曾断崖下滑，**不要线性外推高景气**
4. **估值透支**：凯莱英 PE 53.75 倍，昭衍新药表面增速含水分，追高风险大
5. **减肥药变量**：口服剂型竞争、第三名抢位、安全黑天鹅
6. **Biotech 融资回落**：若全球投融资环境再度恶化，CXO 订单将先行恶化
