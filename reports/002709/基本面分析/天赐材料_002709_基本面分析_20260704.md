**核心指标综合判断:**
2025 年公司从周期底部恢复,收入增长主要来自锂离子电池材料需求增长和价格触底回升;2026Q1 则进入利润弹性释放阶段。优势是扣非利润与归母利润基本匹配,年报审计和内控均为标准无保留意见;压力是 2026Q1 应收账款、存货同步快速上升,经营现金流仍为负,说明利润兑现到现金还有滞后。与新宙邦、多氟多、天际股份等同行相比,天赐材料的 2026Q1 利润弹性更强,但周期属性也更强。

**业务结构判断:**
公司本质上已是锂电材料周期股,2025 年锂离子电池材料占收入 **90.39%**。公司披露 2025 年电池材料产量 106.71 万吨、销量 104.58 万吨,收入 150.51 亿元;其中市场报道和机构口径提到电解液销量超过 72 万吨,但应以公司正式披露口径为准。日化材料毛利率高但体量小,无法决定公司估值中枢。

### 3. 结论摘要
+ 基本面判断:**中性偏强**
+ 财务质量:**良好但需跟踪现金流**
+ 估值状态:**合理偏高**
+ 财务造假风险初筛:**中**
+ 核心理由:
    1. 2025 年主业恢复,2026Q1 利润弹性非常强。
    2. 锂电材料占比过高,盈利高度依赖电解液、六氟磷酸锂等价格周期。
    3. 2026Q1 应收账款和存货环比大增,现金流尚未跟上利润。
    4. 审计意见、内控意见正常,未见已确认的财务真实性重大问题。
    5. 当前市值已反映较多复苏预期,后续关键在 Q2-Q4 盈利与回款能否延续。

### 4. 公司与行业
+ 主营业务:精细化工新材料,核心是锂离子电池材料。
+ 主要产品:电解液、六氟磷酸锂、LiFSI、添加剂、日化材料及特种化学品。
+ 市场占有率:EVTank 口径显示 2024 年天赐材料中国电解液出货量排名第一,国内份额约 31.6%;2025 年公司销量继续增长。
+ 行业景气度:2025Q4 至 2026Q1 景气明显修复,但仍属价格周期驱动。
+ 核心竞争力:电解液一体化、规模、客户资源、核心原料自供与研发。
+ 主要依赖:**单一行业周期依赖明显**,锂电材料占比过高。

### 5. 财务质量验证
+ 利润与现金流匹配:2025 尚可,CFO/净利 0.87;2026Q1 不匹配,净利 16.54 亿但经营现金流 -0.21 亿。
+ 应收账款与营收匹配:2025 应收增长快于收入;2026Q1 应收账款升至 95.81 亿,是最大观察项。
+ 存货与营收匹配:2025 可接受;2026Q1 存货升至 22.82 亿,若价格回落可能产生跌价风险。
+ 资本开支效率与自由现金流:2025 自由现金流 5.23 亿改善;Q1 再度转负。
+ 预付款/其他应收款/在建工程/商誉异常:Q1 其他应收款、存货、应收账款波动较大;商誉约 2.00 亿,规模不大。
+ 资产负债率与有息负债:2025 年末资产负债率 33.02%,2026Q1 负债率约 35.56%,杠杆可控。
+ 综合判断:财务报表没有明显失真证据,但营运资金占用上升使财务质量从"优秀"降为"良好偏谨慎"。

+ 入驻机构家数:年报未直接披露完整机构家数,前十中包括北向、ETF、公募基金。
+ 机构类型:北向资金、公募主动基金、沪深 300 ETF、化工/新能源车电池 ETF。
+ 治理风险判断:实控人控制力强,治理整体正常;需关注 H 股发行对股本和估值结构的影响。

### 7. 估值与同行对比
+ 当前估值:总市值约 1065.76 亿,TTM PE 约 37.2x,PB 约 5.6x。
+ 同行业估值对比:新宙邦 2025 年营收 96.39 亿、归母净利 10.97 亿,增长更稳;多氟多、天际股份 2026Q1 同样受六氟磷酸锂景气修复驱动,利润弹性明显。
+ 同行业质量对比:天赐材料规模和一体化领先,但收入集中于锂电材料,现金流波动和应收压力更值得盯。
+ 估值是否匹配成长与财务质量:若 2026 年高盈利持续,估值可消化;若六氟/电解液价格回落,当前 TTM PE 并不低。

### 8. 负面信息与风险排查
+ 是否亏损:2025 和 2026Q1 均盈利。
+ 是否 ST 或退市风险:未见。
+ 审计意见:2025 年标准无保留意见;内控审计标准无保留意见。
+ 监管问询/处罚:本次核验未见 2026 年重大监管处罚。
+ 诉讼仲裁:公司作为原告的商业秘密侵权诉讼仍有事项在推进,2025 年报披露对生产经营不构成重大影响或尚未判决。
+ 负面新闻:主要集中在周期波动、客户集中、应收上升、扩产及 H 股发行不确定性。
+ 关联交易/客户供应商真实性争议:未见已被监管确认的重大真实性问题。

### 9. 财务造假风险初筛
+ 红旗数量:2 个主要跟踪项。
+ 主要红旗:2026Q1 利润大增但经营现金流仍负;应收账款和存货环比快速上升。
+ 风险等级:**中**
+ 解释:这是财务质量与造假风险初筛,不是事实定性。当前没有看到审计、监管、司法确认的财务造假证据;但若后续应收回款不佳、存货跌价扩大、利润与现金流长期背离,风险等级应上调。

### 10. 后续跟踪清单
+ 跟踪指标 1:2026Q2/Q3 经营现金流能否转正并覆盖净利润。
+ 跟踪指标 2:应收账款周转与坏账计提,尤其是大客户回款。
+ 跟踪指标 3:电解液、六氟磷酸锂、LiFSI 价格与出货量。
+ 触发深度复盘条件:单季毛利率明显回落、存货跌价大增、应收账款继续快于收入增长、H 股发行进展导致估值逻辑变化。
