# Skill: 个股技术走势健康度检查

## 目标

判断一只股票在突破或趋势行情之后，价格与成交量结构是否仍然健康、趋势是否仍然成立。

输出一个明确的技术走势标签，作为辅助验证工具，而不是独立的买卖依据。

适用场景：
- 刚突破关键位置，需要验证突破是否有效、是否有持续追盘。
- 处于趋势延续中，需要确认价量结构是否仍然健康。
- 此前已有看多逻辑，需要用技术走势作为辅助验证。

不适用场景：基本面分析、估值判断、资金与股东行为、是否升级深度复盘。这些交给其他技能。

## 数据纪律

技术走势判断强依赖准确的价量数据，且仅当数据真实可靠时结论才有意义：

- 优先使用权威行情来源获取 OHLCV（开高低收+成交量）数据，例如交易所、行情软件、专业数据接口。
- 若无法获取准确的日线/周线 OHLCV，必须说明信息边界，不可凭粗略价格臆断走势。
- 明确区分已核验的事实与基于有限数据的推断。

## 工作流程

### 0. 先取数

健康度判断建立在数据之上，先拿到所需价量数据，再分析：

- 突破日及此后 1–2 周的日线 OHLCV（开高低收、成交量）。
- 突破周及之后若干周的周线 OHLCV。
- 明确“突破基准”：突破的是哪个位置、哪个价位、什么时间点。

若关键数据缺失，应在输出中标注 `待核验`，不要跳过数据直接给标签。

### 1. 确认是否处于突破或趋势中

先判断个股当前是否处于适用场景：

- 是否刚刚突破某个关键位置（前高、平台、均线、形态颈线等）。
- 是否处于明确的趋势延续中。

兜底：如果当前既没有明显突破、也不在趋势中，应说明“无适用基线”，给出 `需要观察` 并提示等待明确的趋势信号出现，不要强行套用六项检查。

### 2. 检查六类价量行为

依次检查以下信号，逐项给出判断（健康 / 中性 / 偏弱），用具体数据支撑：

1. **突破后追盘**：突破后是否出现持续买入追盘，而不是单日放量后迅速转弱。
2. **日线上涨天数**：突破后 1–2 周，上涨天数是否多于下跌天数。
3. **周线上涨周数**：周线上，上涨周数是否多于下跌周数。
4. **收盘位置（强/弱收盘）**：收盘价收在当日振幅上半区的次数，是否多于收在下半区的次数。
5. **回调弹性（网球行为）**：回调后能否有弹性地反弹，而不是持续阴跌。
6. **成交量结构**：上涨日或上涨周的成交量，是否明显强于下跌日或下跌周。

### 3. 给出技术走势标签

综合六项检查，给出三类标签之一：

- `走势健康`：多数信号显示需求持续，价量结构较为建设性。
- `需要观察`：信号混合，或观察窗口仍然太短。
- `走势转弱`：追盘失败、频繁弱收盘、回调后反弹乏力，或下跌时成交量更大。

### 4. 标记风险与矛盾

技术走势只是辅助验证工具：

- 若技术走势与基本面逻辑相互矛盾，应把它标记为后续风险，而不是强行得出基本面结论。
- 突破失败、放量下跌、反弹乏力等信号，应明确列为风险项。
- 不提供买入、卖出或持有建议。

```text
一句话判断：

走势检查：
1. 突破后追盘：
2. 近1-2周上涨日 vs 下跌日：
3. 周线上涨周 vs 下跌周：
4. 收盘位置（强收盘 vs 弱收盘）：
5. 回调弹性：
6. 成交量结构：

关键证据：
列出最支持当前判断的 2-3 个价量证据。

风险与矛盾：
说明是否存在突破失败、弱收盘、放量下跌、反弹乏力，或技术走势与基本面逻辑不一致的情况。

后续观察：
列出接下来最需要观察的 1-3 个价量信号。
```

## 便于记录版本

每次输出时，末尾都附加此记录块。若某项数据不可得，保留字段并写 `待核验`，不要省略。

```text
技术走势标签：
突破后是否有追盘：
近1-2周上涨日是否多于下跌日：
周线上涨周是否多于下跌周：
强收盘次数是否多于弱收盘：
回调是否有弹性：
上涨成交量是否强于下跌成交量：
后续观察：
```

## 风格

- 默认使用简体中文，除非用户明确要求其他语言。
- 先给标签，再说明推理过程。
- 保持简洁，单只股票通常控制在 200-400 个中文字符。
- 使用专业、谨慎的投资分析语言。
- 不提供个性化买入、卖出或持有建议。
